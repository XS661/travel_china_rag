# 🏔️ 走遍中国 · 智能旅游助手

> 面向全国的智能旅游问答与推荐系统（移动端 Web）

[![Python](https://img.shields.io/badge/Python-3.12+-blue.svg)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.115.0-009688.svg)](https://fastapi.tiangolo.com/)
[![DeepSeek](https://img.shields.io/badge/LLM-DeepSeek-4B6BFB.svg)](https://platform.deepseek.com/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

基于 **RAG（检索增强生成）** 架构的智能旅游问答系统。覆盖全国 140+ 城市（当前 3259 条知识），提供景点介绍、美食推荐、交通指南、行程规划等一站式问答服务。用户只需用自然语言提问，系统从本地知识库中检索相关信息，调用大语言模型生成带来源标注的精准回答。

| ------------- | ------------------------------------------ |

| ⚖️ 对比分析 | "苏州园林和北京颐和园有什么不同？"         |

### 响应式页面（移动端 / PC 端自适应）

系统采用 **移动优先 + 桌面自适应** 设计：手机浏览器全屏自适应（414px 宽度基准）；平板（641–1023px）加宽外壳；**PC 端（≥1024px）自动切换为桌面布局**——左侧品牌导航栏 + 顶部工具条 + 居中会话列，历史记录改为右侧抽屉，社区动态呈多列卡片网格。支持：

- 💬 聊天式对话界面，深色极光玻璃拟态（glassmorphism）视觉
- 📱 城市快捷筛选 chips（点击即选，自动填充示例问题）
- 🏷️ 快捷提问标签 + 欢迎页示例问题引导
- 📝 LLM 生成的分点回答 + 参考来源标注（对话气泡 + 来源胶囊）
- 🔍 检索方式切换（BM25 / 关键词 / 向量 / 混合）与 /compare 对比矩阵
- 📋 最多 20 条问答历史记录（底部抽屉展示，localStorage 持久化）
- ⚠️ API 不可用时自动降级为检索片段原文，顶栏状态灯实时显示后端连接

### RAG 问答流程

```
用户问题 → 城市识别 → 知识库检索(Top-K) → 构造提示词 → LLM 生成 → 答案 + 来源
```

1. **城市识别**：从问题中提取城市名，支持别名（"帝都"→"北京"、"蓉城"→"成都"等）
2. **知识检索**：支持关键词 / BM25 / 向量相似度 / 混合 四种方式，召回最相关的 5 条知识片段，优先匹配目标城市
3. **答案生成**：拼接检索结果 + 系统指令 + 用户问题，调用 DeepSeek API 生成回答
4. **降级兜底**：API 不可用时直接返回检索片段原文，系统不中断

> **向量索引增量式持久化**：向量/混合检索的语料以快照形式持久化在 `backend/data/vector_index/`（`embeddings.npy` + `manifest.json`）。用户投稿审核通过入库后，下一次检索只会对新增条目做增量编码，不再全库重建（按城市分块对齐，上传到任意城市都只产生小规模增量）。删除该目录、更换 `EMBEDDING_MODEL_NAME` 或提升 `VECTOR_INDEX_VERSION` 可强制全量重建；知识库 JSON 写入通过跨进程文件锁串行化，避免并发上传互相覆盖。

| 层级               | 技术                              | 说明                          |

## 🔧 快速开始

### 环境要求

- Python 3.12+（推荐用 [uv](https://docs.astral.sh/uv/) 管理）
- 浏览器（Chrome / Edge）

### 首次安装

```bash
# 1. 克隆项目并进入仓库根目录
git clone https://github.com/XS661/travel_china_rag.git
cd travel-china_rag

# 2. 创建虚拟环境并安装依赖（仅首次，依赖以 pyproject.toml + uv.lock 为准）
uv sync

# 3. 配置 API Key（仅首次）
cd backend
cp .env.example .env
# 编辑 .env，填入你的 DeepSeek API Key
# 不配 Key 也能启动，系统会自动降级返回检索片段原文
cd ..
```

### 每次启动

```bash
# 在仓库根目录运行（任选其一）
uv run uvicorn backend.main:app --host 0.0.0.0 --port 8000
# uv run python -m backend.main
# python backend/main.py
```

看到以下输出即为启动成功：

```
INFO:     Uvicorn running on http://0.0.0.0:8000
[INFO] 知识库加载完成：共 3259 条记录
[启动] 覆盖城市：三亚, 三明, 上海, ...
```

浏览器访问 **http://localhost:8000** 即可使用。按 `Ctrl+C` 停止服务。

### 手机远程访问（可选）

```bash
# 1. 安装 ngrok（仅首次）
winget install Ngrok.Ngrok

# 2. 注册并配置 token（仅首次）
# 浏览器打开 https://dashboard.ngrok.com/signup 注册
# 在 https://dashboard.ngrok.com/get-started/your-authtoken 复制 token
ngrok config add-authtoken 你的token

# 3. 启动内网穿透（每次）
ngrok http 8000

# 将输出的 https://xxxx.ngrok-free.dev 发到手机浏览器即可访问
```

## 📡 API 接口

| 接口               | 方法 | 说明                                  |
| ------------------ | ---- | ------------------------------------- |
| `/api/ask`       | POST | 核心问答：提交问题，返回答案 + 来源   |
| `/api/health`    | GET  | 健康检查 + 知识库统计                 |
| `/api/cities`    | GET  | 获取已覆盖城市列表与标签              |
| `/api/knowledge` | GET  | 分页浏览知识库（支持按城市/分类筛选） |

### 问答接口示例

**请求**：

```bash
curl -X POST http://localhost:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{
    "question": "成都三天怎么玩？",
    "city": null,
    "top_k": 5,
    "method": "bm25"
  }'
```

**响应**：

```json
{
  "question": "成都三天怎么玩？",
  "detected_city": "成都",
  "answer": "根据资料，成都三日游建议如下：\n1. 第一天：大熊猫基地 + 宽窄巷子...",
  "sources": [
    { "id": "travel_cd_010", "title": "成都三日游经典路线", "source": "成都旅游官方指南", "city": "成都" },
    { "id": "travel_cd_003", "title": "成都大熊猫繁育研究基地", "source": "百度百科", "city": "成都" }
  ],
  "retrieval_method": "bm25",
  "model": "deepseek-v4-flash"
}
```

> `method` 可选：`keyword` / `bm25` / `vector` / `hybrid`；设置 `"raw": true` 只返回检索结果与分数、不调用 LLM。

交互式 API 文档：启动后访问 **http://localhost:8000/docs**

## 📚 知识库结构

每条知识为 JSON 对象，包含城市、分类、标题、内容、关键词、来源等字段：

```json
{
  "id": "travel_bj_001",
  "domain": "全国旅游",
  "city": "北京",
  "category": "景点",
  "sub_category": "皇家建筑",
  "title": "故宫博物院",
  "content": "故宫位于北京中轴线的中心...旺季门票60元...需提前预约购票。",
  "keywords": ["故宫", "紫禁城", "北京", "明清皇宫", "世界文化遗产"],
  "source": "故宫博物院官网",
  "source_url": "https://www.dpm.org.cn/",
  "chunk_id": 1
}
```

每个城市 JSON 文件的首条为 `_meta` 元数据，存储城市级配置：

```json
{
  "id": "_meta",
  "city": "北京",
  "category": "_meta",
  "city_tag": "故宫、长城、皇家文化",
  "aliases": ["帝都", "首都", "京城", "北平"]
}
```

### 分类体系

| 分类 | 说明                                   | 每城市条目 |
| ---- | -------------------------------------- | ---------- |
| 景点 | 主要景点介绍、门票、开放时间、游览建议 | ≥8        |
| 美食 | 地方菜系、特色小吃、推荐餐厅           | ≥6        |
| 交通 | 到达方式、市内公共交通指南             | ≥4        |
| 住宿 | 各区域住宿特点与推荐                   | ≥3        |
| 行程 | 1日/2日/3日游经典路线                  | ≥3        |
| 文化 | 地方历史、风俗、特色节庆               | ≥3        |
| 贴士 | 天气、穿着、最佳季节、注意事项         | ≥3        |

**当前统计**：140+ 城市 / 共 **3259 条知识条目**（启动时自动扫描统计）

## 🔄 检索方案对比

| 对比维度   | 关键词匹配                        | BM25                                     | 向量相似度                                   | 混合（BM25+向量）                          |
| ---------- | --------------------------------- | ---------------------------------------- | -------------------------------------------- | ------------------------------------------ |
| 原理       | jieba 分词 + 倒排索引求交集       | 词频(TF) × 逆文档频率(IDF) + 长度归一化  | 文本向量余弦相似度（bge-small-zh 稠密向量）  | BM25 归一化分数 + 向量余弦相似度加权融合   |
| 实现复杂度 | 低                                | 中                                       | 中高（需加载向量模型）                       | 中高                                        |
| 检索速度   | 极快                              | 快                                       | 较快（模型加载后毫秒级）                     | 较快                                        |
| 长文本匹配 | 一般                              | 较好（长度归一化）                       | 好（语义相似度）                             | 好                                          |
| 可解释性   | 强（命中词可见）                  | 中（分数可查）                           | 低（黑盒语义）                               | 中                                          |
| 同义词处理 | 差                                | 差（都依赖分词）                         | 好（可理解语义相近表达）                     | 较好                                        |

默认使用 BM25。前端页面可切换 关键词 / BM25 / 向量 / 混合 四种方式，也可通过 API 参数切换（`method`：keyword / bm25 / vector / hybrid）。访问 **http://localhost:8000/compare** 可进入对比模式：前端自动用四种方式分别检索并展示召回结果、分数与耗时（内部请求 `/api/ask` 且 `raw: true`，不调用 LLM，不暴露额外接口）。

> 向量/混合检索首次调用时会自动下载向量模型 `BAAI/bge-small-zh-v1.5`（约 100MB）并构建索引，之后查询为毫秒级。国内网络如无法访问 HuggingFace，可设置 `HF_ENDPOINT=https://hf-mirror.com` 或配置代理后再启动后端。

## 🛡️ 异常处理

| 异常场景          | 处理策略                                    |
| ----------------- | ------------------------------------------- |
| LLM API 调用失败  | 降级返回检索片段原文，标注"AI 生成暂不可用" |
| 知识库检索无结果  | 提示未收录，列出已覆盖城市                  |
| 城市名未识别      | 全库搜索，提示用户指定城市                  |
| 网络超时          | 30 秒超时，前端给出重试按钮                 |
| API Key 未配置    | 自动降级，不影响基本使用                    |
| 空问题 / 过长问题 | 前端校验 + 后端 Pydantic 校验               |
